# 🌱 Agrizen – AI-Powered Smart Agriculture

Agrizen is an AI-powered smart agriculture platform designed to help farmers make better farming decisions using artificial intelligence and modern technology.

Our mission is to make agriculture smarter, more accessible, and sustainable.

## ✨ Key Features

- Smart Farming Dashboard
- AI-Powered Crop Diagnosis
- Crop Diagnosis History
- AI Farming Assistant Chatbot
- Neural Yield Prediction
- Weather Updates
- Smart Irrigation Management
- Drone Monitoring
- Agricultural Marketplace
- Farming Analytics
- AI-Generated Farm Reports
- Diagnosis PDF Generation
- Alerts and Notifications
- Farmer Community

## 🛠️ Technology Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Firebase
- Google Gemini AI
- Genkit
- Recharts
